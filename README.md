# CanVive: Grow & Earn

BUILD A COMPLETE, POLISHED, RESPONSIVE WEB APPLICATION CALLED "CANVIVE"

============================================================
1. PROJECT OVERVIEW
============================================================

Build a modern sustainability-focused web application called:

CANVIVE

Tagline:
"Every Can. A New Possibility."

Secondary tagline:
"Recycle. Earn. Grow."

CanVive is a smart beverage-can recycling ecosystem.

The concept:
Users recycle beverage cans at CanVive collection stations, earn points, track their recycling activity, grow a virtual plant based on their recycling progress, complete sustainability challenges, compete on leaderboards, and redeem points for rewards.

The website is the DIGITAL PLATFORM for this ecosystem.

The physical CanVive kiosk is not required to be connected to real hardware in this prototype. Instead, create a "Demo: Recycle a Can" function that simulates a successful can recycling event.

The website must feel like a REAL PRODUCT/STARTUP rather than a basic college project.

Use realistic mock data and simulated functionality.

Do NOT require:
- Real payment systems
- Real SMS OTP
- Real hardware APIs
- Paid APIs
- Real reward partners
- Real map APIs

Use mock/local data for the prototype.
